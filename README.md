**CareMesh: "A Personalized Medicine Platform"**

This platform helps the doctors and patients track their treatment plans and their medicine update.

**Features:**

	1. Authentication Module 
	2. Patient Management Module
	3. Analysis Engine Module
	4. Research & Visualization Module
	5. AI Interaction Module

**Tech Stack:**

	1. Programming & Interface: Python, Streamlit
	2. Interoperability & Standards: HL7 FHIR (Fast Healthcare Interoperability Resources), JSON
	3. Big Data Analytics: Apache Parquet
	4. Machine Learning & Logic: Scikit-Learn, Random Forest, XG Boost
